SISTEM ADOPSI HEWAN
Sistem Adopsi Hewan adalah sistem yang dirancang untuk mempermudah pengelolaan data operasional pada sebuah tempat penampungan hewan. Aplikasi ini bertujuan untuk mendigitalisasi proses pencatatan hewan yang ditampung serta mengelola data rekam jejak masyarakat yang melakukan transaksi adopsi.
Melalui sistem ini, petugas dapat melakukan pengelolaan data (Create, Read, Update, Delete) untuk mendata profil hewan, memantau status ketersediaan hewan (Tersedia atau Sudah Diadopsi), dan menyimpan data riwayat pengadopsi secara terstruktur melalui integrasi database relasional.
